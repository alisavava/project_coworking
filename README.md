# Новая идея компании 
Мы начали делать и поняли что сложно подобрать хорошие источники, все которые мы подобрали, нормально не парсятся, поэтому пришлось менять тему 

Делаем груминг салон с опцией доставки животных. 

То есть наш салон может приехать на дом, забрать питомца, отвезти его на груминг и привезти назад. Это делает нас независимыми по району (позволяет обслуживать богатых клиентов, не платя за помещение в дорогих районах). Также позволяет охватить новые группы покупателей, которым необхидима доставка.

## Старая идея компании
Делаем коворкинг, совмещенный с кофейней. 

Похоже на нынешние кофейни, в которых сидят люди с ноутбуками, но гораздо удобнее для работы/учебы и гораздо дешевле обычных коворков благодаря продаже еды и напитков. 

Система депозитов: для входа платится депозит, который затем можно тратить на напитки/еду из кофейни.
